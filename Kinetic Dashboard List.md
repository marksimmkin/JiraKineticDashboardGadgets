List of issues that are in the JQL with configurable columns for the information the user wants to display.

Use the selected Controller JQL, narrowed to statuses the Controller shows, and preserve its ordering by default. Clicking a column heading sorts all matching issues by that field, ascending first and descending on a second click. The sort replaces the filter's own ORDER BY and stays in place across Controller filter changes and dashboard refreshes until the gadget reloads; it isn't saved. Fields that Jira can't sort by show an error instead. Each List gadget has its own Edit view for choosing and ordering up to 10 columns from Jira's field catalogue, including custom fields. Default to Issue key, Summary, Status, and Assignee. Load 50 issues at a time with a Load more button so large filters remain usable. Show a "Hiding:" note below the filter name.
