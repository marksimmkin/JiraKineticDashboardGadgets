List of issues that are in the JQL with configurable columns for the information the user wants to display.

Use the selected Controller JQL and preserve its ordering. Each List gadget has its own Edit view for choosing and ordering up to 10 columns from Jira's field catalogue, including custom fields. Default to Issue key, Summary, Status, and Assignee. Load 50 issues at a time with a Load more button so large filters remain usable.
