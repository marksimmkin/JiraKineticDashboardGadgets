List of users affected by the JQL which have graphical bars next to each person showing the total total weighted score on issues that are assigned to them.

Treat users as assignees of issues in the selected Controller JQL, with Unassigned shown separately. For each person, sum the configured remaining-work weight of their issues' current statuses (1 means not started, 0 means complete). Sort largest remaining score first and scale graphical bars against the highest score. Show issue counts as context.

Show only statuses listed in the Controller with Show ticked, and show a "Hiding:" note naming the others. Hidden statuses and their issues are excluded from scores, rankings, and issue counts.

Total time remaining is the sum of Remaining Estimate, shown as days then hours, for example 6.0d (42h), using the hours per day set in this gadget's Edit view (default 7).
